# Cheminformatics Virtual Laboratory

**Authors:**  ALOK KUMAR
**Institution:** SRM Institute of Science and Technology, Tiruchirappalli  

## Overview
An interactive, browser-based learning environment for exploring cheminformatics concepts, molecular structures, and molecular-property descriptors.

## Features
- **7 Workspaces**: Multi-tool environment for cheminformatics analysis.
- **3Dmol.js**: Interactive 3D molecular structure visualization.
- **Chart.js**: Dynamic data charting and visualization.
- **jsPDF**: Seamless export of laboratory reports to PDF.

## Deployment Steps
1. Clone the repository to your local machine or server.
2. Ensure `index.html` is configured as the main entry point (`app_file: index.html`).
3. Deploy to any static site hosting service (e.g., GitHub Pages, Hugging Face Spaces).
